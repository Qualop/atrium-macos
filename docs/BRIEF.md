# Atrium 인계 문서

0.4 소스 통합의 목적과 유효한 결정을 정리한다. 원본 P111까지 반영하면서 Mac·제공자별 native 기록·워커 상한을 유지한다. 통합·native 실행 환경·패키징 확인은 진행 중이다. 구조는 `docs/ARCH.md`, 남은 일은 `docs/PLAN.md`, 결정의 경위는 `docs/decisions.md`에 둔다.

## 1. 왜 만드는가

여러 AI 코딩 작업을 겹쳐 돌려도 결과를 검토하고 다음 지시를 정하는 일은 사람에게 남는다. 최근 활동 순으로 바뀌는 목록만으로는 각 작업의 자리와 맥락을 기억하기 어렵다.

Atrium은 모든 프로젝트의 에이전트와 터미널을 한 캔버스에 놓고, 상태가 바뀌어도 사용자가 정한 자리를 지킨다. 내 답이 필요한 작업과 아직 보지 않은 결과를 구분하고, 어느 세션에든 보드에서 바로 말을 건다. 에이전트끼리 맡긴 일과 역할은 연결선과 미션 트리에 남긴다.

## 2. 무엇을 만드는가

herdr가 터미널과 프로세스를 소유하고, Atrium은 세션을 띄우고 연결하며 그 상태와 오가는 일을 보여준다. 실제 코딩과 작업 분담은 각 CLI 에이전트가 한다. 워크트리 생성과 모델 인증도 각 제공자의 규칙을 따른다.

주 화면은 프로젝트 전체를 가로지르는 캔버스다. 데스크톱 앱 밖의 실행 중인 터미널에 붙어 입력하지 않는다. 사용자가 고른 데스크톱 대화는 별도 사본으로 가져올 수 있으며, 원본과 사본의 식별자·수명을 구분한다. 원격 브라우저도 같은 호스트의 보드를 조작하는 클라이언트이며, 호스트의 명시적 활성화와 기기 등록이 필요하다.

| 도구 승인 | `agentAutoApprove` 공개 기본값은 false다. 명시적으로 승인한 설치 보드에서만 켜며 관리 제공자의 실행·복구에 자동 옵션을 적용한다. 전역 CLI 설정은 고치지 않는다(2026-11-11). | 로그인·신뢰·질문은 사람이 답한다. PC 카드는 응답 필요 안내·OS 알림과 실제 터미널 이동으로 바꾼다. |
| 모델 목록 | Codex는 `model/list`, Gemini CLI는 설치 메타데이터, agy는 `agy models`를 쓴다. Claude 별칭과 게이트웨이 목록을 더해 자연어 이름을 찾는다. 모호하거나 없는 이름은 후보를 반환한다(2026-11-05). | 정적 Codex 단일 모델이나 이름 접두어만으로 제공자를 추정하지 않는다. 목록과 사용 권한은 다르다. |
| 명령과 비밀 값 | 추가 인자는 따옴표와 배열 경계를 보존한다. 명령 호출자는 원문과 env를 분리해 프로세스에 전달한다. 값은 로컬 프리셋·비공개 runtime에 저장되며 공개 이벤트에는 env 값과 원문 명령을 노출하지 않는다(2026-11-05). | 터미널에 비밀 값을 앞머리로 타이핑하지 않는다. 로컬 저장은 암호화된 비밀 보관함을 뜻하지 않는다. |
| 워크스페이스 | git 공통 폴더를 저장소 키로, 일반 폴더를 폴더 키로 쓴다. 워크트리는 리포 내부 상자다. 폴더가 저장소로 바뀌면 노드·메모·칸반·도킹·가상 그룹 소속을 함께 이행한다(2026-11-05). | 같은 저장소가 두 영역으로 갈라지지 않게 한다. 프로세스나 원본 체크아웃을 이동시키는 기능은 아니다. |
| 프로젝트 그룹 | 안팎 폴더를 자동 가상 그룹으로 묶고 사람이 정한 이름·순서·제외를 보존한다. 관계를 고려해 정리하되 파일 시스템과 전송 대상을 만들지는 않는다(2026-11-11). | 프로젝트 정리와 세션 전송을 구분한다. |
| 일반 셸 | 에이전트 없는 패널도 노드로 둔다. 셸에서 에이전트가 나타나면 같은 노드의 종류를 바꾼다. 셸에는 명령 바 요청을 보내지 않고 터미널에 직접 입력한다(2026-11-05). | 에이전트 준비 상태를 알 수 없는 직접 명령에 첫 지시를 자동 제출하지 않는다. |
| 협업 | 역할 연결과 herdr 호출·결과를 기록한다. Claude·Gemini·agy는 제공자별 hook·기록을 사용하고 Codex는 관리 세션 문맥과 세션 범위 자격 증명을 쓴다. 다른 판을 부르는 herdr 옵션을 자동으로 붙이지 않는다(2026-11-05). | 상세 신호가 없는 제공자에 없는 답이나 tool 결과를 만들지 않는다. |
| 스킬 | Claude에는 herdr와 `atrium` 스킬, 옛 `delegate` 별칭, child 명령 shim을 관리 플러그인으로 준다. Codex 문맥은 기존 사용자·개발자 지시를 대체하지 않는다(2026-11-05). | 사용자 전역 설정과 AGENTS 파일을 덮지 않고 판 사용법을 알린다. |
| 가지 펼치기 | `atrium child`는 제공자·호환 모델을 상속하고 제공자가 다르면 부모 권한을 변환한다. 기본 상한은 직접 자식 4개·깊이 3·보드 전체 하위 16개다. 동시 예약·자손 정리를 유지한다(2026-11-11). | 권한 변환과 자동 모드 승인은 워커 상한 제거를 허용하지 않는다. |
| 워크트리 신뢰 | Claude의 미신뢰 저장소에서는 먼저 일반 세션으로 신뢰 질문을 보인다. 사람이 신뢰하고 같은 패널의 준비를 확인한 뒤 `--worktree`로 다시 띄우며 그동안 지시를 보류한다. 커밋 없음은 거부하고 시간 초과로 신뢰를 대신하지 않는다(2026-11-05). | trust autoaccept 없이 판 안에서 절차를 마친다. `atrium child-wait`로 기다린다. |
| 화면 구조 | 하나의 캔버스에 세션·내부 워크트리 상자·미션·가상화 사이드바를 둔다. 혼합 워크트리 도킹과 워커 열, 관계별 정리·되돌리기를 지원한다. 한글 표시 이름과 에이전트 주소를 구분한다(2026-11-11). | 위치 기억과 기존 주소를 유지한다. |
| 화면 조작 | 연결선은 터미널 내용을 덜 가리게 배치한다. 스크롤 기록 선택·복사, 요청 기록의 필터·재전송, 화면/터미널 글자 크기, 방향키·공통 대화상자를 제공한다. Mac 단축키·IME·붙여넣기 처리는 유지한다(2026-11-05). | 긴 기록과 많은 세션을 다룰 때도 입력 초점과 선택을 잃지 않게 한다. |
| 언어와 에셋 | 영어·한국어 UI를 제공하며 기본은 영어다. 문서는 한국어를 원칙으로 하고 기존 영문 README를 함께 유지한다. 참고 제품의 코드·이름·로고·에셋을 가져오지 않으며 MIT·의존성·글꼴 고지를 유지한다(2026-11-05). | 화면 참고와 저작물 복제는 다르다. 외부 도구 표시는 제휴를 뜻하지 않는다. |
| 프로세스 구조 | 전용 herdr 서버, Node 백엔드, Electron 또는 등록된 브라우저 클라이언트로 나뉜다. API는 loopback에서 듣는다. 클라이언트별 뷰포트와 공유 터미널 제어기를 사용한다(2026-11-05). | 화면 수명과 세션 수명을 분리하고 여러 클라이언트의 크기·알림 소유권을 정한다. |
| 원격 접속 | 기본 꺼짐이다. 호스트가 켠 뒤 기기를 등록하고 Tailscale Serve·사용자/기기 정책을 확인한다. 쿠키 세션과 선택적 패스키를 사용하며 패스키 기본값도 꺼짐이다. Funnel은 쓰지 않는다(2026-11-11). | 등록 기기는 호스트 터미널 권한을 가진다. |
| 휴대폰 알림 | 휴대폰 보드·미션·터미널과 기기별 Web Push를 제공한다. 알림 권한·푸시 구독은 기기에서 허용하고 원격 차단 시 구독을 지운다(2026-11-11). | 푸시 서비스 이용을 원격 접속 허용과 구분한다. |
| 앱 업데이트 | `Qualop/atrium-macos`의 stable/dev 완성 번들을 검증해 설치 Mac 앱을 교체한다. 체크섬·서명·호환성 검사와 이전 번들 복구를 둔다(2026-11-11). | 원본 저장소 소스 빌드로 설치 앱을 덮지 않는다. |
| herdr 세션 | 판 전용 이름 있는 세션을 깨끗한 환경으로 띄운다. 사용자의 기본 herdr 세션을 채택하거나 종료하지 않는다(2026-10-30). | 다른 작업의 세션과 프로세스를 보호한다. |
| 세션 식별 | 보드 UUID와 native 대화 ID를 구분한다. Claude·Gemini·agy·관리 Codex는 각 제공자의 정확한 ID와 새 관리 설정으로 복구한다. 알려진 대화의 증거가 없으면 임의의 최신 대화나 새 대화로 바꾸지 않는다(2026-11-05). | 폴더와 시각으로 대화를 추정하거나 서로 다른 실행이 같은 기록을 쓰는 일을 막는다. |
| 잠재우기 | 자격 있는 관리 Claude에 프로젝트·세션 절전 범위를 둔다. 프로젝트가 바빠도 개별 절전할 수 있고 프로젝트 깨우기는 개별 절전·미사용 사본을 제외한다. Codex 사본은 고른 UUID만 깨운다(2026-11-11). | 작업·신뢰·초안·전달·루프를 보호하고 한꺼번에 깨우지 않는다. |
| 판 밖 대화 | 기존 Claude CLI 기록 색인·묶임 검사·missed 분류를 유지한다. 다른 곳에 묶인 원본을 판에서 재개하지 않는다. 판 밖 원본 터미널은 실시간 제어하지 않는다(2026-11-05). | 원본 보호와 명시적 사본 가져오기를 구분한다. |
| 데스크톱 가져오기 | Claude와 Codex 목록은 기본 선택이 없고 고른 항목만 복사한다. Claude는 별도 스냅샷, Codex는 native `thread/fork` 사본을 잠듦으로 등록한다. 가져오기 자체로 원본을 재개·보관·종료하거나 턴을 시작하지 않는다(2026-11-05). | 원본과 사본의 ID 및 이력을 보존한다. Codex의 다른 클라이언트 활동 여부는 단정하지 않는다. |
| 삭제와 복구 | 닫힘·보관·기록 삭제·프로젝트 제거를 구분한다. 지원되는 파일 삭제는 확인 후 휴지통으로 보낸다. 복구 실패는 까닭을 남기고, 실패한 새 패널을 닫지 못했으면 추적을 유지한다(2026-11-05). | 원본 대화나 형제 패널을 잘못 정리하지 않는다. |
| 실험 | 기존 사용자 세션·기본 herdr·실제 기록은 읽기 외에 건드리지 않는다. 시험은 합성 데이터와 분리한 프로필·폴더·자격 증명에서 한다. 실제 서비스 작업은 별도 승인된 세션만 사용한다(2026-11-05). | 가져오기 기능이 기존 세션을 시험 대상으로 삼을 권한은 아니다. |

## 4. 사용성 원칙

- 자리는 사람이 정하고 시스템은 유지한다. 상태 알림 때문에 노드를 옮기지 않는다.
- 내 차례와 검토 대기는 프로젝트 전체를 가로지르되 서로 구분한다.
- 돌아온 세션에는 마지막 지시·답·필요한 행동을 먼저 보여준다.
- 연결은 역할과 실제로 오간 일을 보여준다. 관계가 없는 출력이나 완료 상태를 추측하지 않는다.
- 자동 모드는 도구 승인에 적용한다. 로그인·신뢰·질문은 터미널에서 사람이 답하며 종료·삭제·루프 확인은 유지한다.
- 기능 설명, 실제 검증 결과, 배포 상태를 구분한다.

## 5. 현재 범위

P111까지의 실행·협업·배치, 쿠키·패스키·휴대폰·푸시, Mac 번들 업데이트를 통합한다. Mac·Node 지원, native Codex 사본·정확한 UUID와 Gemini/agy 기록·복구를 유지한다.

사설 도구 연결, 판 밖 원본 터미널 제어, 무제한 워커는 포함하지 않는다. 기능 범위와 최종 검증·배포 상태는 구분한다.

## 6. 남겨 둘 확인 항목

실제 IME 후보 창과 언어 전환, 물리 재부팅, OS 알림 클릭, CPU·OS 조합별 설치, 실제 계정의 제공자별 권한, 원격 브라우저의 절전·재접속은 자동 계약 시험과 구분한다. 기록 복사는 원본 불변성·식별자 분리·실패 복구를, 원격 접속은 기본 꺼짐·명시적 활성화·기기 회수·토큰 비노출을 계속 확인한다. 최종 판정과 증거는 지휘 세션이 기록한다.
