# Atrium 계획

## 지금: 설치본과 원격 기기의 실사용 점검

사용자가 고른 기기에서 로그인·재연결·알림 클릭·절전 복귀를 확인한다. 구조와 API는 ARCH 1~7절을 따른다.

- 실제 iPhone·브라우저 푸시 전달과 OS 알림 직접 클릭을 확인한다.
- 긴 협업 작업과 재시작에서 정확한 native ID·비공개 실행 값·닫힌 기록을 점검한다.
- 실사용 근거가 있는 화면·자원 문제를 분리해 개선한다.

완료 기준은 실기기 재현 조건과 수정 범위가 있고 워커 상한·기존 데이터·명시적 원격 허용을 유지한 검증 결과가 있는 것이다.

## 다음: 실사용 회귀 보강

실사용에서 확인된 재현을 자동 검사에 반영한다. 설치·재접속과 기존 기록의 호환성을 유지한다. 다른 CPU·OS 빌드는 해당 기기의 검증 근거를 확보한 뒤 배포한다.

완료 기준은 재현·수정·검증의 연결이 있고 배포 파일과 확인한 환경이 일치하는 것이다.

## 열린 결정

- 판 밖에서 채택한 제공자에 관리 설정을 연결할지. 출처와 정확한 대화 ID가 없는 세션의 자동 복구는 확대하지 않는다.
- 검색을 보드 색인 밖으로 넓힐지, 루프 종료 판정을 답의 글자 일치 밖으로 넓힐지.
- 실사용 결과에 따라 터미널 연결 예산·원격 알림 표현과 프로젝트별 전송 동선을 더 조정할지.
