# Atrium 계획

## 지금: v0.3 사용 피드백과 회귀 방지

macOS에서 실행 프리셋·모델 선택, 프로젝트 그룹·워크트리 상자, 대화 복사와 선택적 원격 접속을 사용하며 발생하는 문제를 재현한다. 대상 제공자는 Claude Code·Codex·Gemini CLI·Antigravity이고, 현재 구조는 ARCH 1~7절을 따른다.

- 사용자 데이터와 기존 세션을 보존한 격리 환경에서 문제를 재현한다.
- 보드 상태·프리셋·정확한 native 대화 ID·터미널 연결 세대가 재시작과 재접속 후에도 일치하는지 살핀다.
- 실제 외부 Tailscale 기기·Safari·절전 복귀와 Windows GUI는 실기기 검증 범위로 남긴다. 자동 시험 결과와 구분해 기록한다.
- 사용자 원본 대화는 테스트 대상으로 복사·재개·종료하지 않는다. 실제 원격 설정은 사용자가 요청한 경우에만 변경한다.

완료 기준: 제보마다 재현 조건과 수정 범위를 확인하고, 해당 기능의 회귀 시험과 설치본 동작을 검증한다.

## 다음: 원격 접속과 긴 작업의 실사용 점검

목표:

- 사용자가 선택한 원격 기기에서 재연결·절전 복귀·입력·선택 동작을 확인한다.
- 긴 작업 중 보드 복구와 협업 기록의 정확성을 점검한다.
- 미통합 보안 제안은 실제 구현과 근거를 검토한 뒤 별도 범위로 결정한다.

완료 기준: 실사용 재현 자료가 있고, 필요한 개선만 분리해 검증하며, 워커 상한과 기존 승인 설정을 유지한다.

## 열린 결정

- `herdr agent prompt|wait|read` 자동 승인 범위를 자기 자손으로 좁힐지. 현재는 같은 사용자 보드의 다른 에이전트에도 접근한다.
- 워커 상한을 변경할 필요가 있는지. 현재 기본은 직접 자식 4개·깊이 3단계·전체 하위 16개이며, 자동 제거하지 않는다.
- 일반 사용자에게 원격 접속을 어느 범위까지 권할지. 등록 기기는 호스트의 터미널 권한을 가지며, 미통합 P56~P59 제안은 별도 검토 대상이다.
- 판 밖에서 채택한 제공자 세션에 관리 설정을 연결할지. 출처와 정확한 대화 ID가 없는 세션을 자동 복구 대상으로 확대하지 않는다.
- 검색을 보드 색인 밖의 전체 대화 기록까지 넓힐지, 루프의 종료 판정을 답의 글자 일치 밖으로 넓힐지.
- 실제 사용 결과에 따라 전역 `@all` 외의 프로젝트별 보내기, 연결선·도킹 배치와 터미널 연결 예산을 더 조정할지.
