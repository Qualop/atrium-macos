상태: 닫힘
날짜: 2026-11-02

## 지시

새 Codex 세션에서 모델명을 자동 감지하여 드롭다운으로 선택하도록 바꾸고, 이름 필드를 세션 이름으로 명확히 표시한다. 설치 앱에도 반영한다.

## 작업 기록

설치된 Codex의 stdio app-server에서 initialize → initialized → model/list만 요청한다. 대화·추론은 만들지 않고 조회 프로세스는 성공·실패·시간 초과 때 종료한다. 페이지네이션, 숨김·중복 제외와 UTF-8 스트림 처리를 포함한다.

새 세션에 모델 드롭다운, 기본 설정 사용, 직접 입력, 새로고침, 로딩·빈 목록·오류 안내를 추가했다. 실행 인자는 고급 설정으로 접었다. 선택한 모델이 실행 인자의 이전 모델 옵션보다 우선하고, 자동 감지 실패 시 직접 입력할 수 있다. 모델 목록은 계정별 사용 권한을 보장하지 않는 Codex 카탈로그다.

모델 목록을 고정 문자열로 저장하지 않는다. 모델 조회에는 공식 app-server 프로토콜(https://learn.chatgpt.com/docs/app-server)을 사용한다.

## 보고

소스 실행 환경과 /Applications/Atrium.app 설치본 모두 모델 8개 자동 조회, 선택값 전달, 실패·빈 목록·직접 입력·새로고침, 900×600 창 배치 검증을 통과했다. 백엔드 281개, 화면 71개 테스트와 빌드가 통과했다. 설치본 코드 서명을 검증하고 앱을 다시 열었다. 실제 모델 추론은 실행하지 않았다.
