## 지시

여러 AI 작업을 한 보드에서 관리하고 역할로 연결하며, 중단·재시작 이후에도 작업 맥락을 유지한다는 앱 목적을 기준으로 모든 기능군을 재검토한다. 재현한 결함을 수정하고 설치 앱·GitHub에 반영한다. 실제 사용자 세션과 데이터 제공 거절 설정은 유지한다.

## 작업 기록

검토 범위를 나누어 진행한다. 세션/대기열/하위 세션/절전/복구, 공급자 실행/설정/설치, 보드/터미널/연결/화면, 반복 작업/메모/칸반/요청 기록/검색을 독립 검토한다. 부모 작업은 API 수신, 종료 대상 범위, 늦은 결과, native 완료 처리와 실제 통합 시험을 담당한다.

- 시작 기준: main 70f53f3, 작업 트리 깨끗함. 기존 백엔드/화면 시험을 기준으로 삼되 통과 여부만으로 결함이 없다고 판단하지 않는다.
- 종료 시 패널 목록 실패를 빈 목록으로 간주해 작업 공간 전체를 닫는 경로, 닫기 실패 후 노드를 제거하는 경로, 중복 종료 요청을 재현했다.
- 닫히거나 패널이 바뀐 세션에 늦은 화면 조회 결과가 적용되고, 이전 턴의 답변이 새 턴을 덮는 경우를 재현했다.
- 이전 Antigravity 완료 callback이 새 invocation을 종료하거나 초기화 전 대화 ID를 되돌리는 경우를 재현했다.
- API의 JSON null/배열/잘못된 요청 형태가 dispatcher 밖에서 예외를 내는 경우를 재현했다.

## 보고

검토 기준은 세션 수를 늘려도 작업·입력·맥락을 잃지 않고, 한 세션의 조작이 다른 작업을 망가뜨리지 않는 것이다. Gemini 연동만의 검토가 아니다.

### 수정한 문제

| 기능군 | 재현 후 수정한 문제 |
|---|---|
| 세션 종료 | 패널 목록 조회 실패·새 형제 패널 생성 중 작업 공간 전체가 닫힐 수 있었음. 개별 패널만 닫는다. 실제 닫기 실패 시 노드를 남기고 실패를 알린다. 동시 종료는 한 작업으로 합친다. 절전·복구 실패 정리에도 같은 규칙을 적용했다. |
| 메시지 전달 | 제출 hook이 RPC보다 먼저 올 때 다음 전송이 겹침. 작업 시작을 확인했는데 늦은 RPC 오류로 중복 전송될 수 있음. 재시작 시 전송 기준 시각이 현재로 바뀌어 확인 가능한 지난 제출을 놓침. |
| 늦은 결과 | 닫히거나 패널·턴이 바뀐 세션에 옛 화면 조회·답변·승인 선택지가 적용됨. 이전 Antigravity 완료 callback이 새 invocation을 끝내거나 초기화 전 대화 ID로 되돌림. |
| 연결·터미널 | 분할 수신된 UTF-8 한글 손상. 구독 응답 누락으로 이후 구독까지 정지. 중지 뒤 늦은 구독 응답이 연결을 되살림. 교체된 제어기의 늦은 입력·크기 변경·detach가 새 제어기에 적용됨. |
| API | JSON null·배열·잘못된 요청 형태가 dispatcher 밖에서 예외를 냄. 객체 상속 속성을 API 이름으로 받아들임. |
| 하위 세션 | 비동기 검사 중 이름·수량 상한 경합, 진행 중 요청 이중 집계, 닫힌 중간 부모 아래 자손 누락, DeepSeek 설정 상속 누락, 명령 응답을 잃었을 때 자식 생성 알림 누락. |
| 보관·복구 | 동시 다시 열기로 같은 세션이 중복 생성됨. Codex 모델 변경이 재실행 인자에 적용되지 않음. Claude /clear 후 옛 대화 ID로 재개·등록될 수 있음. 열기 실패 시 재시도 불가능한 노드가 남거나 다른 패널을 정리할 수 있음. |
| 반복 작업 | 생성·재개 전 시간이 실행 시간으로 더해짐. 연결이 끊기면 마감 처리가 늦어짐. 취소 뒤 idle 루프가 정지함. 기존 화면 글이 새 조건으로 발동함. 중지 뒤 늦은 화면 조회가 전송함. 무관한 답변을 목표 달성으로 간주함. |
| 요청 기록·출력 | 이전 답변이 새 요청에 붙거나 같은 턴이 두 결과에 붙음. 재시작 후에도 같은 문제 발생. 여러 블록의 한 요청이 별도 턴으로 나뉨. 화면/native/hook 기록 중 일부가 사라짐. 소수 페이지 크기로 SQLite 오류. |
| 메모·칸반 | 삭제·프로젝트 닫기와 비동기 갱신이 겹치면 지워진 대상을 되살리거나 없는 프로젝트 소속으로 남김. 동시 카드 추가·일괄 작업 실패 시 롤백도 확인했다. |
| 검색·프로젝트 | 예전 Gemini/Antigravity 답변이 검색에서 빠짐. 따옴표·역슬래시 검색이 JSON 저장 표현 때문에 누락됨. 루트 폴더의 하위 폴더를 다른 위치로 오인. 종료 후 늦은 worktree 조회와 오래된 캐시 적용. |
| 보드 배치 | 오래된 스냅샷이 드래그·삭제 결과를 덮음. 도킹 크기 조절 중 새 스냅샷이 원위치로 돌림. 취소한 드래그가 계속 움직임. Ctrl+클릭 다중 선택 실패. 긴 노드 잘림·좁은 패널 과도 확대. |
| 화면·포커스 | 지난 세션으로 지연 포커스가 돌아감. 삭제한 노드의 선택·입력이 남음. 끊긴 터미널의 늦은 attach가 입력을 다시 켬. 오래된 검색 결과·리뷰 기록을 선택하거나 표시함. |
| 설정·새 세션 | 중복 submit, 이전 폴더의 신뢰 예측 표시, 저장 응답이 새 입력을 덮음, 언어 변경 실패 후 화면·선택 불일치. 빈 숫자·상속 속성을 유효한 설정으로 수용함. 지표 조회 실패가 보드 초기화를 막음. |
| 트레이 | 실패한 구독의 클라이언트 누수, stop 뒤 늦은 연결 부활, 종료 뒤 대기 알림 발송. |
| 모델·프로필 | Codex 기본 모델·인용부호·설정 override·인자 종료 처리, Gemini 묶음 옵션·모델 상수 로딩 순서·세션 프로필 재생성, null 모델이 문자열로 저장됨. 잘못된 응답·큰 응답·stream 오류로 모델 조회가 깨짐. 사용자가 끈 agy hook 상태 보존. |
| 설치 | 실패한 다운로드 임시 파일, 서명 실패 후 부분 앱 산출물, 재시도 방해. 실행 앱 이동 후 외부 Node 경로가 없어지면 CLI shebang 실행 실패. 스테이징→서명/검증→최종 배치와 번들 Node 경로 설정으로 수정. |

### 검증의 한계

물리적 Mac 재부팅, 실제 한글 IME 후보창·입력기 전환, Windows·Intel 실기기의 모든 UI, 모든 제공자 계정의 권한·사용량 제한·네트워크 장애 조합은 이 환경에서 완전 검증하지 않았다. 중요한 분기는 회귀 자료와 장애 주입으로 검증했으며, 자동 시험 통과를 모든 가능한 버그의 부재로 해석하지 않는다. 과거 Claude 대화 자동 색인·절전은 원래 지원 범위를 유지한다.
