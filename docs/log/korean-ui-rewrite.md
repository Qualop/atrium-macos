상태: 닫힘
날짜: 2026-11-02

## 지시

이해하기 어려운 한국어 UI를 전반적으로 다시 작성하고 설치된 macOS 앱에 반영한다. 기능, 모델 ID, 실행 옵션과 승인·삭제 의미는 유지한다.

## 작업 기록

한국어 문구 1,090개를 공통·세션·프로젝트 관리 영역으로 나눠 검토하고 약 900개를 다시 썼다. 사전을 ko-core.js, ko-sessions.js, ko-workspace.js와 선택 항목용 ko-controls.js로 분리했다. 기존 키와 자리표시자는 모두 유지한다.

| 이전 용어 | 변경 |
|---|---|
| 내 차례 | 응답 필요 |
| 검토 | 확인할 결과 |
| 덩어리 | 창 그룹 |
| 가지 펼치기 | 하위 세션 생성 |
| 미션 맵 | 작업 관계도 |
| 루프 | 반복 작업 |
| missed | 정리 대상 대화 |
| 잠재우기·깨우기 | 절전 모드·작업 재개 |
| 워크스페이스 | 프로젝트 |
| Thread | 요청 기록 |

승인 방식과 추론 강도의 표시 이름도 한국어로 바꿨으며 내부 옵션값은 유지한다. Command를 지원하는 Mac 단축키의 표시만 바꾸고 Ctrl+C 등 터미널 제어 키는 그대로 둔다. 대화 연결 상태의 기존 한국어 판정과 사용자 메시지의 원문을 보존한다.

길어진 설명이 새 세션 창 밖으로 넘치지 않도록 최소 너비·체크박스 배치를 보완했다. 보관, 삭제, 앱 종료, 모든 작업 종료는 서로 다른 결과를 명시한다. 세션 이름 예시는 실제 ASCII 입력 규칙에 맞췄다.

## 보고

기존 문구 897개 수정, 선택 항목 등 14개 문구 추가. 화면 단위 시험 73개 및 빌드 통과. 기존 한국어 키 누락 없음, 자리표시자 변경 없음. 소스 실행과 /Applications/Atrium.app 설치본에서 설정 6개 탭을 900×600으로 확인하고 권한 표시 변경 후에도 plan/manual 값이 그대로 저장됨을 검증했다. 세션 생성 화면·요청 기록·언어 전환·Mac 단축키·모델 드롭다운도 확인했다. 설치본의 터미널 입출력과 재연결 시험도 통과했다. Claude·Codex 자체의 응답이나 외부 CLI 오류 원문은 앱 번역 대상에 포함하지 않는다.
