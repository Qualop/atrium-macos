날짜: 2026-11-02

## 지시

현재 Mac에 Atrium을 일반 응용 프로그램으로 설치하고 실행 실패를 수정한다.

## 작업 기록

Electron 앱에 화면 빌드, 백엔드, Node 24, herdr 0.9.5, 필요한 런타임 의존성을 포함했다. 사용자 컴퓨터에서 확인한 CLI 실행 경로는 앱 내부 runtime/cli-paths.json에 저장한다. 시스템 PATH·로그인 자동 실행 설정은 변경하지 않는다.

첫 설치본의 제한된 PATH 시험에서 spawn node ENOENT가 재현됐다. app.isPackaged 조건으로 앱 내부 Node와 CLI 경로 처리를 건너뛰는 것이 원인이었다. 내부 런타임 파일 존재 여부로 선택하도록 수정했다.

## 보고

- 설치 경로: /Applications/Atrium.app. 이 컴퓨터용 ad-hoc 서명이며 배포용 공증은 아니다.
- 실제 설치본을 새 시험 프로필과 기본 시스템 PATH로 실행하여 백엔드·herdr 연결, 셸 입력·출력, 창 재열기, 백엔드 재시작 후 같은 pane 복구를 확인했다.
- 화면 단위 시험 71개 통과. codesign 검증과 원본·설치본 main.mjs 일치 확인.
- 사용자 실사용 대화·설정은 변경하지 않았다. 실행은 Finder에서 Atrium.app을 연다.
- 설치본은 소스 폴더와 독립된 복사본이다. 이후 소스 변경은 다시 패키징·설치해야 반영된다.
