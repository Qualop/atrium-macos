날짜: 2026-11-04

## 지시

Node.js 지원 범위를 실제 호환되는 버전까지 넓히고 다운로드 가능한 GitHub 릴리스를 만든다.

## 작업 기록

- 필요 기능은 내장 node:sqlite이며 Node 24만의 API를 사용하지 않는다. Electron의 빌드 도구 요구 조건도 확인했다.
- 공식 배포처에서 SHA-256을 검증한 Node 22.13.0, 22.23.4, 24.0.0, 24.22.2, 26.0.0, 26.13.0을 별도 폴더에 설치해 백엔드·앱 시험과 빌드를 수행했다. 시스템 Node는 바꾸지 않았다.
- 지원 범위는 ^22.13.0 || ^24.0.0 || ^26.0.0이다. Node 20 이하에는 내장 SQLite가 없고, 22.12 이하에는 플래그 문제가 있다. 수명이 끝난 홀수 계열과 27 alpha는 지원 범위에 넣지 않는다.
- 기존 20ms 대기에 의존한 전달 시험이 병렬 부하에서 실패해, 실제 보내기/확인 이벤트를 기다리도록 바꿨다. 제품 코드를 우회하거나 시험을 제외하지 않았다.
- Node 26의 Database 이름을 우선 사용하고 구버전의 DatabaseSync로 호환한다.
- 배포 파일에 빌더의 개인 CLI 경로를 저장하지 않는다. 실행하는 Mac의 표준 경로와 nvm 설치를 런타임에 찾아 쓴다.
- 앱 버전 0.2.0, macOS Apple Silicon용 ZIP·DMG·SHA256SUMS를 만든다. Node 24.22.2와 herdr 0.9.5를 포함한다. Node·Electron/Chromium·herdr·npm 런타임 라이선스도 포함한다.

## 보고

- 6개 Node 버전 각각에서 백엔드 459개·앱 96개 시험 및 빌드 통과. 버전별 설치 경로나 전역 기본 Node는 변경하지 않았다.
- CI도 macOS·Windows × 최소/최신 Node 22·24·26의 12개 조합으로 확대했다.
- ZIP을 새 경로에 풀어 앱 서명·개인 경로 미포함을 확인하고, 최소 PATH에서 모델 선택·한국어·보드/도킹/메모/칸반/검색/보관·터미널·재연결 시험을 통과했다.
- DMG는 읽기 전용 마운트 후 내부 앱 서명과 Applications 바로가기를 검증했다. ZIP·DMG의 SHA-256 목록을 함께 배포한다.
- 런타임 패키지 32개의 라이선스 목록과 원문, 별도 Node·Electron/Chromium·herdr 고지를 포함했다. Pretendard의 OFL은 기존 THIRD_PARTY_NOTICES에 포함한다.
- 빌드 위치 차이가 소스 맵/주석 경로를 바꾸지 않도록 esbuild의 기준 폴더를 고정했다.
- 배포 대상은 macOS 13 이상 Apple Silicon이다. 앱은 ad-hoc 서명이며 Apple 공증은 포함되지 않는다. Windows·Intel 앱 바이너리를 검증한 것으로 표시하지 않는다.
