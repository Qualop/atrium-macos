## 지시

macOS 포팅 후 검증 범위를 실패·경합·재시작 경로까지 넓히고, 재현한 문제를 회귀 시험과 함께 수정한다. 기존 사용자 세션과 대화는 사용하지 않는다.

## 작업 기록

테스트를 먼저 추가해 실패를 확인한 뒤 아래 문제를 수정했다.

터미널 연결 전·오프라인에는 입력을 비활성화하고 연결 상태를 표시한다. 재연결 때 기존 초점을 복원하며, 종료한 터미널의 힌트 타이머와 캔버스의 resize 리스너를 정리한다. Command-K를 캡처 단계에서 처리하고 검색창의 예약된 초점 이동을 취소할 수 있게 했다.

기존의 빠른 통합 시험은 백엔드의 준비와 화면·터미널의 준비를 구분하지 못했다. 화면 소켓·터미널 제어기가 실제 준비된 시점을 기다리고, 실패 때 screenshot·최근 이벤트를 남기도록 보강했다. 이 과정에서 검색창 표시 직후 아직 초점이 오기 전에 Escape를 누르던 시험 자체의 타이밍 문제도 고쳤다.

## 보고

최종 결과: 백엔드 277개, 화면 71개 단위 시험 모두 통과(실패·취소·건너뜀 0). 화면 빌드, 문서 규약, git diff --check 통과. 실패 재현 시험 16개를 추가해 수정 전 실패와 수정 후 통과를 확인했고, 배치 상태 변경 2,000회 속성 시험도 추가했다.

Apple Silicon 네이티브 herdr와 Rosetta의 Intel용 herdr 각각에서 아래 실제 통합 시나리오가 모두 통과했다. Node와 Electron은 두 실행 모두 arm64이며, Intel Mac 실기기 검증은 아니다. Intel 바이너리 SHA-256도 공식 v0.9.5 값과 대조했다.

- 한글·공백·따옴표·달러 기호가 들어간 새 폴더에서 세션 생성.
- 같은 이름 동시 요청은 하나만 성공, 이름 없는 7개 동시 요청은 서로 다른 이름 생성.
- 9개 세션에서 터미널 제어기 상한 8개, 축소 시 0개, 확대 시 재연결. 선택한 노드의 연결 보장.
- 실제 키 입력·xterm 출력, 여러 줄 한글 붙여넣기의 제출 전 대기, Command-F·Command-K.
- 합성 IME 이벤트: 조합 중 전송 없음, 확정된 한글 음절만 한 번 전송, 명령 바 값 보존.
- 메모·칸반 생성, 카드 12개 동시 추가, 한국어 설정 저장.
- WebGL 컨텍스트 손실 시 대체 렌더러로 전환, renderer 예외 없음.
- 창 종료·재열기, 백엔드 SIGKILL 뒤 같은 pane 및 9개 세션·메모·카드 12개 복구, 다시 입력 가능.
- 재시작 후 일반 셸과 herdr 서버의 실제 메모리 조회.
- herdr 정지 중 생성 요청 거부, herdr 재시작 후 새 터미널 생성·종료.

모든 시험용 프로세스가 종료되었음을 확인했다. 전체 로그와 화면은 backend/.dev/verification/deep/에 보관한다(git 제외). 다시 실행: backend와 app 각각 npm test, app에서 npm run test:mac:stress. 실제 사용자 대화·설정은 시험 자료로 사용하지 않았다.

검증 범위: 동시 세션 생성, 연결 상한, 축소·확대, 한글 여러 줄 붙여넣기, 합성 IME 조합·확정, 단축키, 메모·칸반·언어 설정, WebGL 손실, 창 재열기, 백엔드 SIGKILL 뒤 WAL·세션 복구, herdr 중단·재시작, 프로세스 메모리 조회. 배치 알고리즘은 고정 난수로 2,000회 상태 변경 후 노드 집합·겹침·면적·최소 크기를 검사한다.

성능 표본: 10.2MiB·10,001행의 합성 대화 파일을 이 Mac에서 읽었을 때 최근 메시지 조회 약 13ms, 복구 조회 약 14ms였다(단일 측정). 동기 파일 읽기 방식은 유지하므로 더 큰 실제 대화와 많은 세션의 동시 조회 부하는 별도 측정이 필요하다.

남은 외부 검증: Windows와 Intel Mac 실기기, 실제 IME 후보 창·한/영 전환, 물리 재부팅, 실제 OS 알림 클릭, 로그인·신뢰 이후 Claude/Codex/DeepSeek의 모델 작업. 합성 IME 이벤트나 Rosetta 실행은 이 항목의 대체 검증이 아니다.
