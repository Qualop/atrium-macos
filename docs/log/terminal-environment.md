상태: 닫힘
날짜: 2026-11-04

## 지시

최종 스트레스 시험 화면에 남은 nvm 오류를 제거하고 새 터미널 실행 환경을 검증한다.

## 작업 기록

기능 시험을 통과한 9개 터미널 화면을 직접 확인하던 중 npm_config_prefix가 app 폴더로 설정됐다는 nvm 경고를 발견했다. npm --prefix로 앱을 실행할 때 생긴 실행 도구의 prefix가 herdr 서버와 로그인 셸에 상속되고 있었다.

## 보고

- npm lifecycle에서 시작한 경우에만 npm_config_prefix(대소문자 변형 포함)를 자식 엔진 환경에서 제외한다. 일반 실행에서 사용자가 지정한 prefix, registry, 다른 환경 변수는 유지한다.
- 회귀 시험에서 수정 전 실패와 수정 후 통과를 확인했다. 실제 macOS 시험은 새 셸의 처음 화면에 해당 경고가 없는 것도 검사한다.
- 최종 로컬 백엔드 시험은 458개 통과했다. 실제 터미널 입력·창 재실행·백엔드 재시작도 통과했다. 기존 사용자 herdr 세션을 강제로 재시작하지 않았다.
