## 지시

분석한 원본 ad0c39f의 구현 기능 P30~P55를 macOS 분기에 통합한다. 실행 프리셋, 모델 이름 선택, 터미널/사이드바/요청 기록, 프로젝트 그룹/워크트리 상자/영역 재분류, 데스크톱 대화 복사, 다중 클라이언트·웹·Tailscale을 포함한다. Claude 외에 Codex도 지원한다. 워커 상한 제거와 미통합 P56~P59 보안 기능은 제외한다. 기존 Mac·Node LTS·Gemini/Antigravity 지원과 경합 수정, 개인정보 제공 거절 설정을 유지한다.

## 작업 기록

- 통합 브랜치 codex/upstream-v03, 기준 ed921b4. 분석 문서는 보존한다.
- 원본과 우리 변경을 3-way 비교로 준비한 뒤 파일별 담당을 나누어 기능을 통합한다. 소스 교체 시 현재 세대 검사·입력 직렬화·개별 패널 종료·경로 정규화를 보존한다.
- 원격 접속은 기본 꺼짐으로 제공하고 명시적 활성화가 필요하다. Tailscale 실제 설정은 바꾸지 않으며 가짜 프록시로 시험한다.
- Codex 대화는 native app-server의 복제 경로를 사용하고, 원본을 재개·보관·종료하지 않는다. 시험은 합성 기록과 별도 개발 보드로 수행한다.
- 2026-11-05: 기능별 3-way 통합 뒤 기존 경합 수정과 Mac 실행 경로를 다시 대조했다. 실행 프리셋의 환경 변수는 PTY 명령문에 넣지 않고 프로세스 환경으로 전달한다. 원시 명령은 비공개 런타임에만 두고 이벤트·응답에는 표시용 값만 남긴다.
- 2026-11-05: 프로젝트 키 변경 시 그룹 소속도 같은 트랜잭션에서 옮긴다. 실패 시 세션·메모·칸반·좌표·그룹을 함께 되돌리는 시험을 추가했다. 터미널에는 클라이언트별 연결 세대 검사를 더했다.
- 2026-11-05: 실제 Electron의 별도 시험 보드에서 동시 세션 9개, 제어기 상한 8개, 배율에 따른 연결 해제·복원, 한글 붙여넣기·조합, 백엔드 강제 종료 후 같은 패널 재연결을 확인했다. 프리셋·모델·한국어 화면 시험은 별도 보드에서 진행했다.
- 2026-11-05: Node 22.13.0/22.23.4/24.0.0/24.22.2/26.0.0/26.13.0에서 백엔드 691개·앱 228개 및 빌드를 검증했다. 이후 추가 수정은 별도로 다시 검증한다.
- 2026-11-05: 설치 앱과 사용자 보드의 SQLite 일관성 백업을 만들었다. 실행 중인 실제 herdr 서버와 에이전트 세션은 그대로 유지한다.

## 보고

승인한 P30~P55 실행 기능을 통합했다. 실행 프리셋과 실제 모델 조회·이름 해석, 터미널 선택·기록, 사이드바·요청 기록, 프로젝트 그룹·워크트리 상자·영역 재분류, Claude/Codex 대화 복사, 여러 클라이언트·웹·Tailscale 접속을 포함한다. 워커 상한 제거와 미통합 P56~P59 패스키·기기 결합 구현은 제외했다. 원격 접속은 기본 꺼짐이며 실제 Tailscale 설정은 변경하지 않았다.

통합 과정에서 실행 환경을 잃는 어댑터 경로, 명령 프리셋의 비밀 값 노출·재열기 누락, 프로젝트 키 변경 시 그룹 소속 손실, 공유 터미널의 오래된 연결 이벤트, 첫 구독의 알림 담당 정보 누락을 수정했다. Codex는 정확한 사본 UUID와 협업 문맥 전달 여부를 즉시 저장하고, 대화·출력 조회와 결과 저장도 native 기록을 사용한다. 출력 조회 도중 세션이 바뀌면 이전 결과를 새 세션에 저장하지 않는다. 가져오기 화면은 기본 선택 없음·중복 제출 잠금·늦은 응답 무시를 적용했다.

- 최종 로컬 검증: 백엔드 715개, 화면 228개 통과. Node 22.13.0/22.23.4/24.0.0/24.22.2/26.0.0/26.13.0에서 시험과 빌드를 확인했다. Node 24.0의 하위 시험 완료 대기 차이는 시나리오 본문을 명시적으로 기다리도록 고쳤다.
- GitHub CI: 실행 코드가 같은 커밋 `2fb2a07`에서 macOS·Windows × Node 6개, 12개 작업 모두 통과했다. [실행 결과](https://github.com/Qualop/atrium-macos/actions/runs/42029938729). Windows의 기존 플랫폼 전용 6개 백엔드 시험은 건너뛰며 나머지 709개가 통과했다. 테스트 자체의 DB 정리 순서·셸 선택·8.3 경로·기본 플랫폼 가정을 수정했고 제품 코드를 약화하지 않았다.
- 브라우저 검증: 기존 경합 19개, 통합 화면 11개, 터미널·폴더 탐색, 대화 가져오기 중복 제출·선택·오류 안내, 전체 백엔드와 HTTPS/WSS 웹 접속을 확인했다. 실제 원격 서비스 대신 임시 인증서와 합성 Tailscale 응답을 썼다.
- 배포 앱 검증: 최소 PATH에서 번들 런타임으로 실행했다. 실제 Codex·Gemini CLI 모델 조회, 프리셋 입력, 한국어 화면, 메모·칸반·배치·보관, 동시 세션 9개와 제어기 상한 8개, 한글 IME·여러 줄 붙여넣기, 강제 종료 후 같은 패널 복구를 통과했다. agy 모델 선택과 Codex 대화 복사·리뷰어 경로는 합성 자료로 검증했으며 실제 사용자 원본에는 작업을 보내지 않았다.
- macOS v0.3.0 설치 완료. 실제 기존 4개 세션의 ID와 패널, 실행 엔진 PID, 한국어·워커 제한 설정을 보존했다. 이전 앱과 SQLite 일관성 백업을 별도 보관했다. 설치본의 실행 소스 201개가 저장소와 일치한다.
- ZIP·DMG 생성, 서명 검사, ZIP 압축 해제 검사, DMG 내부 체크섬 및 SHA-256 검증을 마쳤다. Node 24.22.2·herdr 0.9.5와 의존성 라이선스를 포함한다. 공개 트리의 비밀 값·개인 경로 검사와 문서 닫기 검사를 통과했다.

실제 외부 Tailscale 기기, Safari, Windows GUI, 사용자 원본 Codex 대화의 복사는 이 자동 시험에 포함하지 않았다. Codex의 별도 클라이언트에서 원본이 실행 중인지 항상 확인할 수 없어 화면에서 그 한계를 안내한다. 자동 절전은 기존 Claude 대상 범위를 유지하며 가져온 Codex 사본은 선택했을 때만 깨운다. macOS 배포 파일은 ad-hoc 서명이며 Apple 공증은 포함하지 않는다.
