## 지시

원본 dev 1c43c02(v0.2.1-dev.8, 정식 v0.2.0 포함)까지 기능을 macOS 분기에 통합한다. 터미널 엔진을 herdr에서 herdr-core(hc)로 바꾸고 macOS에서 돌게 한다. 원본 코드(대부분 Codex가 작성)의 결함을 찾아 고친다. Claude 계정 두 개를 따로 로그인해 쓸 수 있게 한다. 노드 머리의 닫기 같은 단추를 누르기 쉽게 한다. 워커 상한 4/3/16, 원격 기본 꺼짐, Gemini(agy) 단일 아이콘, native Codex·Gemini·agy 연동, 동적 모델 목록, Mac Cmd·IME·붙여넣기 처리를 유지한다. 실제 판은 백업과 검증 뒤 마지막에 옮긴다.
