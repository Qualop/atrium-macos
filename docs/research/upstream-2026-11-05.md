# 원본 Atrium 변경 분석과 macOS 분기 적용 후보

날짜: 2026-11-05

원본에는 실행 프리셋과 모델 이름 해석, 큰 보드 관리, 터미널 선택·기록, 데스크톱 세션 복사, 여러 클라이언트·웹 원격 접속이 추가됐다. 우리 v0.2.0에는 없는 기능이 많지만, 원본 파일로 덮어쓰면 Mac 경로·Gemini/Antigravity 통합과 최근 경합 수정이 손상될 수 있다. 작은 사용성 수정부터 가져오고, 모델·보드 구조를 단계별로 합치는 편이 적합하다.

## 따로 판단할 변경과 중복 수정

**하위 세션 상한 제거는 실제 동작 변경이다.** 원본은 개수·깊이·보드 전체 상한을 없앴다. 우리는 기본 4개/깊이 3/전체 16개와 동시 예약 검사를 갖고 있다. 워커 안내 스킬·신뢰 확인 흐름은 가져오되, 상한 제거는 별도 제품 결정으로 두는 편이 좋다. [상한 없는 생성 경로](https://github.com/Gudals0320/atrium/blob/ad0c39f705410d5ef7fae3a4ae8c67ff009ef9a1/backend/src/branch.mjs#L378)

**자동 복귀 브리핑도 제거됐다.** 우리에는 자리를 비웠다가 세션에 들어올 때 요약을 보여주는 기능이 있다. 원본은 바로 사용하는 흐름으로 바꿨다. 요청 기록·글자 크기 개선을 가져오기 위해 이 삭제까지 따를 필요는 없다. [브리핑 제거](https://github.com/Gudals0320/atrium/blob/ad0c39f705410d5ef7fae3a4ae8c67ff009ef9a1/app/src/renderer/touch.js#L1)

**이미 공유된 작업은 다시 가져오지 않는다.** 원본은 우리가 보고한 이슈 #1의 16개를 P29에서 수정했고, P39는 Qualop의 번역을 바탕으로 한국어를 다시 정리했다. 번역 커밋에는 Qualop 공동 저자 기록도 있다. 다만 이후 새 기능의 새 번역 키는 필요하다. [`9db1f8e`](https://github.com/Gudals0320/atrium/commit/9db1f8e), [`bf8fe2a`](https://github.com/Gudals0320/atrium/commit/bf8fe2a), [번역 출처](https://github.com/Gudals0320/atrium/blob/ad0c39f705410d5ef7fae3a4ae8c67ff009ef9a1/app/src/renderer/locales/ko.js#L1)

새 사용성 수정 P50~P53은 별도 후보다. 배치 틀이 다른 노드를 덮는 문제, 새/먼 메모 편집 진입, 빈 보드 안내, 공통 대화상자 키보드, 저장소 밖 HEAD 표시, 첫 시작을 재시작으로 세는 문제 등이 포함된다. 여러 줄 붙여넣기는 우리 Mac에도 이미 처리가 있으므로 Windows용 Shift+Enter 바이트를 그대로 가져오면 안 된다. [`cfc57f1`](https://github.com/Gudals0320/atrium/commit/cfc57f1), [`d293352`](https://github.com/Gudals0320/atrium/commit/d293352), [`2851182`](https://github.com/Gudals0320/atrium/commit/2851182), [Windows 셸 붙여넣기](https://github.com/Gudals0320/atrium/blob/ad0c39f705410d5ef7fae3a4ae8c67ff009ef9a1/app/src/renderer/lib/term-input.js#L7)

P54의 시작 준비 대기와 동시 backend start 재사용은 우선 후보다. 우리 API에는 같은 준비 대기 기능이 없지만 relay를 만드는 순서는 원본 P40보다 빠르다. 원본과 동일한 오류가 우리에서 재현됐다고 단정하지 않는다. P55의 하나는 모델 오류 중복 판정 수정이고, 다른 하나는 시험용 backend.json 완성 대기다. 운영 코드의 backend.json 쓰기를 원자적으로 만든 변경은 아니다. [준비 대기](https://github.com/Gudals0320/atrium/blob/ad0c39f705410d5ef7fae3a4ae8c67ff009ef9a1/backend/src/api.mjs#L42), [동시 시작 재사용](https://github.com/Gudals0320/atrium/blob/ad0c39f705410d5ef7fae3a4ae8c67ff009ef9a1/backend/src/client.mjs#L72), [`9f35687`](https://github.com/Gudals0320/atrium/commit/9f35687)

개발 흐름에는 CHANGELOG 분리, 작업 기록 공개, 비밀값·개인 경로·파일 크기를 검사하는 커밋/푸시 훅이 추가됐다. 실행 앱의 새 기능과는 별개이며, 원본 검사기는 docs/research를 금지하는 등 우리 문서 규칙과 다른 정책을 갖고 있다. [공개 검사기](https://github.com/Gudals0320/atrium/blob/ad0c39f705410d5ef7fae3a4ae8c67ff009ef9a1/scripts/check-public.mjs#L1)

## 아직 공개 main에 없는 원격 보강

P56~P59는 이 기준 커밋에서는 작업 지시서다. P59에 “별도 작업이 끝났다”는 서술은 있으나, 해당 구현의 main 통합을 증명하지 않는다. `web-auth.mjs`, `passkey.mjs`, `remote-log.mjs`도 이 트리에 없다. [`9b2d453`](https://github.com/Gudals0320/atrium/commit/9b2d453), [`ad0c39f`](https://github.com/Gudals0320/atrium/commit/ad0c39f)

- 패스키 로그인·HttpOnly 세션: 현재 공개 코드는 기기 토큰을 localStorage에 저장하고 Bearer 또는 WebSocket 쿼리로 보낸다. [현재 토큰 방식](https://github.com/Gudals0320/atrium/blob/ad0c39f705410d5ef7fae3a4ae8c67ff009ef9a1/app/src/renderer/web.js#L10)
- Tailscale 기기 자체에 인증을 묶는 기능: 현재는 계정 확인 중심이며, 기기별 whois 결합은 후속 작업이다.
- 연결 감사 기록·PC에서 일시 연결 종료·원격 차단 스위치·다른 기기를 해제하지 못하게 하는 제한: 통합 지시서에 남아 있다. 현재 기기 목록·이름 변경·짝 해제는 존재한다. [현재 기기 API](https://github.com/Gudals0320/atrium/blob/ad0c39f705410d5ef7fae3a4ae8c67ff009ef9a1/backend/src/web.mjs#L435), [남은 통합 요구](https://github.com/Gudals0320/atrium/blob/ad0c39f705410d5ef7fae3a4ae8c67ff009ef9a1/docs/log/p59-remote-integrate.md#L19)

따라서 “원격 접속은 구현됨”과 “패스키 기반 원격 보강 완료”를 구분해야 한다. P47의 로컬 다중 클라이언트를 먼저 검토하고, 외부 원격 접속은 보강이 main에 들어온 뒤 함께 평가하는 순서가 적합하다. 원본 원격 시험도 Tailscale 시뮬레이터 중심이며 Mac Safari·절전 복귀는 별도 검증 대상이다.

## 우리 분기에서 보존할 것

1. **Mac 실행과 배포:** Application Support, Unix 소켓, POSIX 프로세스/경로, Command 키, 번들 Node·herdr, Node 22.13/24/26 지원을 유지한다. 원본 패키지의 Node 범위는 여전히 24 전용이고 기본 경로·탐색에는 Windows 가정이 남아 있다.
2. **실제 모델 목록:** 우리 Codex model/list, Gemini CLI 메타데이터, Antigravity agy models를 P41의 목록 재료로 사용한다. 원본의 정적 Codex 한 항목으로 대체하지 않는다. GPT라는 이름만으로 항상 Codex를 실행하는 것도 아니다. 게이트웨이 모델은 Claude CLI로 실행된다.
3. **공급자별 협업:** Gemini/Antigravity hook, 부모 종류 상속, 세션별 설정·환경, 정확한 대화 ID 복구를 유지한다. 특히 원본 createWorkspace는 호출자가 준 env를 받지 않아 그대로 덮으면 우리 공급자 연결이 깨진다. [충돌하는 환경 처리](https://github.com/Gudals0320/atrium/blob/ad0c39f705410d5ef7fae3a4ae8c67ff009ef9a1/backend/src/herdr/adapter.mjs#L310)
4. **경합 수정:** 보내기 직렬화, 종료 대상 패널 보호, 최신 턴/대화 확인, snapshot 병합, 연결 세대와 controllerPid 검사를 유지한다. P47은 제어기를 공유하므로 클라이언트별 붙기 세대까지 구분할 필요가 있다.
5. **권한·신뢰:** 프리셋 선택이 승인 모드까지 바꾸는 동작을 명확히 보여준다. 원본의 PowerShell 환경 변수 접두어와 공백 기반 인자 분리를 Mac에 그대로 적용하지 않는다. 신뢰 관문의 시간 초과 때 trusted=false인데도 다음 단계로 가는 흐름도 보완한다.
6. **데스크톱 가져오기:** 원본 대화 ID는 보존하지만 같은 체크아웃에서 작업할 수 있다. 파일·세션·가져오기 장부를 등록하다 실패하는 경우의 롤백, 실행 중 원본 선택, Mac 경로를 보완한다. 가져오기는 사용자 선택으로만 수행한다.
7. **데이터 이행:** P37의 workspace 키 변경과 P44의 그룹 membership을 함께 옮긴다. 현재 원본의 그룹 정규화는 사라진 키를 제거하므로 이행 없이 결합하면 그룹 소속이 빠질 수 있다. [그룹 키 정규화](https://github.com/Gudals0320/atrium/blob/ad0c39f705410d5ef7fae3a4ae8c67ff009ef9a1/backend/src/ws-groups.mjs#L15)

이 항목들은 코드 비교에서 확인한 적용 조건이다. 원본의 모든 결함을 재현하거나 보안 검사를 완료했다는 의미는 아니다.
